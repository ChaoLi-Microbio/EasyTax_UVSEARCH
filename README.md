# Simplfied taxonomy analysis by U/VSEARCH pipeline with Ref databases of gg2/slv138.1
## 6 versions of public databases normalized, used for U/VSEARCH (gg2 and/or slv138.1 are recommended)
### Note: This is the 16s amplicon dataset process adapted and briefed from EazyAmplicon(https://github.com/YongxinLiu/EasyAmplicon.git) using U/VSEARCH, targeting relatively precise community analysis of bacteria taxonomy.

Environment deployment:
1. First install EazyAmplicon from https://github.com/YongxinLiu/EasyAmplicon.git
2. Download 'db' folder of this project
3. Download gg2.fa and/or slv138.1.fa, put it into 'db' folder
4. Running 'u_vsearch(clean).sh' in terminal step by step
5. Running 'visualization.R' step by step for taxonomy visualization

There you go!
